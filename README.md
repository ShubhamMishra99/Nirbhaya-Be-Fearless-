# 🛡️ Nirbhaya – Women's Safety Platform

**Nirbhaya** is a web-based safety platform designed to empower women and provide them with essential tools for emergencies. It enables users to send instant SOS alerts, track live locations, and access vital helpline numbers—all within a secure and intuitive interface.

👉 **Live Demo:** [https://v0-women-s-safety-website.vercel.app/](https://v0-women-s-safety-website.vercel.app/)  
⭐ *Give it a star if you find it helpful!*

---

## 🚀 Features

- **🚨 SOS Alerts:** One-tap alerts to notify emergency contacts and nearby volunteers.
- **📍 Live Location Tracking:** Real-time location sharing using the OpenStreetMap API.
- **📞 Helpline Numbers:** Quick access to essential national and local helpline numbers.
- **🔐 Authentication:** Secure signup/login to protect user data.
- **📊 Dashboard:** Centralized access to all safety features.

## 📦 Installation

Follow these steps to run the project locally:

1. **Clone the repository**
   ```bash
   git clone [repository URL]
   cd nirbhaya-women-safety
   ```

2. **Install backend dependencies**
   ```bash
   npm install
   ```

3. **Configure MongoDB**
   - Set up a MongoDB database (e.g., MongoDB Atlas or local instance).
   - Add the MongoDB URI in your environment config file (e.g., `.env`).

4. **Run the application**
   ```bash
   npm start
   ```

## 🧭 Usage

- **Signup/Login:** Create an account or log in to use the safety features.
- **SOS Button:** Tap to send instant emergency alerts.
- **Location Tracking:** Turn on to share your live location with trusted contacts.
- **Helpline Access:** View and dial important helpline numbers directly.
